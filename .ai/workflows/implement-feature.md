# Workflow: implement a feature

**Agent:** backend-engineer or frontend-engineer, depending on scope.
**Read first:** context.md, current-state.md, the relevant spec(s) in specs/, relevant architecture doc.
**Steps:** confirm the feature is covered by an existing spec (if not, route to architect first via the
documentation-first policy), implement, write tests, update `docs/current-state.md`.
**Done when:** tests pass and current-state.md reflects the change.
