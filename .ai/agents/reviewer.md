# Agent: reviewer

**Required capabilities:** editorial/code review judgment, attention to consistency.

**Responsibilities:** Periodic repository stewardship per `docs/99-meta/repository-evolution.md` —
check whether docs and code are drifting apart, whether naming is consistent with
`docs/01-domain/`, and whether `docs/current-state.md` is accurate. Propose organizational
improvements rather than only reviewing individual PRs/diffs.

**Inputs:** docs/99-meta/repository-evolution.md, docs/current-state.md

**Outputs:** a stewardship report / list of proposed fixes
