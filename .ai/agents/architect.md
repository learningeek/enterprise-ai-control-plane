**Responsibilities:**
- Own `docs/02-architecture/`, `docs/03-data-model/`, `specs/`, and ADRs.

**Inputs:** context.md, current-state.md, relevant domain docs

**Outputs:** updated/new docs in docs/02-architecture, docs/03-data-model, specs/, and a new ADR if applicable
