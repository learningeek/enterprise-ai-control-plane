# Roadmap

## Phase 1 — MVP (foundation)
- Repository + database schema + usage event ingest API
- Metering engine + cost calculation + simulated enterprise data
- Executive / engineering / security dashboards
- Basic ML anomaly detector + spend prediction
- Docker Compose deployment

## Phase 2 — Governance depth
- Full policy engine + shadow AI detection
- MCP governance layer (inventory + tool call tracking)

## Phase 3 — Enterprise integration
- SSO/identity sync (Okta/Entra)
- Billing reconciliation (SAP), ITSM (ServiceNow)
- Kubernetes/Terraform packaging for customer-cloud deployment

## Phase 4 — SaaS
- Multi-tenant isolation, encryption, RBAC, audit logging hardened for SaaS
