# Enterprise profile (simulation target)

- 25,000 employees across 12 business units / 10 departments (Engineering, Finance, Sales, Marketing,
  HR, Legal, IT, Operations, Security, Procurement)

- ~40 MCP servers
- Multiple providers: OpenAI, Azure OpenAI, Anthropic, AWS Bedrock, internal models
- 100,000-500,000 AI usage events for a representative period
